# 🤖 Бот-автоотклик для hh.ru (HeadHunter)

Автоматизированный помощник для быстрого отклика на вакансии на платформе HeadHunter. Бот ищет подходящие вакансии по заданным фильтрам и автоматически отправляет на них отклики с прикрепленным резюме.

## 📝 Переменные окружения (файл `.env`)

Для настройки бота создайте в корне проекта файл `.env` и задайте следующие переменные:

| Переменная | Тип | Обязательная | Описание                                                                                | Пример                     |
|------------|-----|--------------|-----------------------------------------------------------------------------------------|----------------------------|
| `SEARCH` | `str` | ✅ | Поисковый запрос (ключевые слова для поиска вакансий); можно указать несколько через запятую — по каждому будет выполнен отдельный поиск | `"Python разработчик,Django разработчик"` |
| `WORK_FORMAT` | `str` | ❌ | Желаемый формат работы (можно перечислить через запятую)                                | `"REMOTE", `               |
| `VACANCY_HTML` | `str` | ✅ | Путь к временному файлу с вакансиями для парсинга                                       | `"temp/vacancies.html"`    |
| `PARSED` | `str` | ✅  | Путь временному файлу сосписком id спарсеных вакансий                                   | `"data/parsed.json"`       |
| `CHROME_BINARY` | `str` | ✅  | Полный путь к исполняемому файлу Chrome (если браузер установлен в нестандартном месте) | `"/usr/bin/google-chrome"` |
| `APPLIED` | `str` | ✅ | Путь к JSON‑файлу для хранения истории отправленных откликов (создаётся автоматически)  | `"applied_history.json"`   |
| `COVER_LETTER` | `str` | ❌ | Универсальный текст сопроводительного письма, подставляется во все вакансии, где оно запрашивается | `"Здравствуйте! ..."`      |

### 🔧 Как заполнить `.env`

1. Скопируйте шаблон:
   ```bash
   cp .env.example .env
   ```
2. Отредактируйте .env, указав свои значения.

## 🐳 Запуск в Docker

В образе уже есть Chromium, chromedriver и виртуальный дисплей, поэтому ставить браузер на хост не нужно.

1. Создайте `.env` (см. выше). Значения `CHROME_BINARY`, `APPLIED` и `PARSED` внутри контейнера переопределяются образом.
2. Соберите образ:
   ```bash
   docker compose build
   ```
3. Запустите весь пайплайн (`search.sh` → `parse.py` → `apply.py`):
   ```bash
   docker compose run --rm --service-ports hh
   ```
4. Когда скрипт попросит войти в аккаунт, откройте http://localhost:6080/vnc.html?autoconnect=true&resize=scale, войдите на hh.ru и нажмите Enter в терминале.

Вход сохраняется в томе `chrome-profile`, поэтому при следующих запусках логиниться заново не нужно — достаточно нажать Enter. История откликов `applied.json` монтируется с хоста. Порт 6080 открыт только на `127.0.0.1`: у noVNC нет пароля.

Дополнительные переменные: `CHROME_PROFILE_DIR` (каталог профиля Chrome) и `CHROME_EXTRA_ARGS` (доп. флаги Chrome через пробел).
